# Security policy

JARVIS-1 is a security tool, so a flaw in it can hide an attack or become one.
Please report vulnerabilities privately rather than in a public issue.

**Report to:** chris.kagabe@gmail.com, or use GitHub's private vulnerability
reporting on this repository (Security → Report a vulnerability).

Please include the version or commit, what you observed, and the smallest steps
that reproduce it. We aim to acknowledge reports within 3 working days and to
agree a disclosure date with you.

In scope: anything that lets JARVIS-1 report a clean result it did not
verify, lets fetched content (feeds, research, model output) clear or suppress a
finding, exposes the dashboard beyond loopback, records key values, or leaks
configured credentials.
